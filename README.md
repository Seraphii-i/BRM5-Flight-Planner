# BRM5 Flight Operations Planner

A static, GitHub Pages-ready flight planning website for Blackhawk Rescue Mission 5 roleplay.

## Features
- UH-60 variant / callsign fields
- Mission type, ROE/status, flight rules, formation, altitude, weather and loadout
- Ordered waypoint planner with grid references
- Printable mission brief
- Save/load/delete previous flight plans
- JSON export/import
- No backend required: saved plans use browser localStorage
- Responsive dark tactical UI

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and this README.
3. In **Settings → Pages**, choose the `main` branch as the publishing source.
4. Open the generated GitHub Pages URL.

GitHub Pages can publish static HTML/CSS/JavaScript directly from a repository.
